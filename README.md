# Love Read Book Store

Love Read Book Store เป็นโปรแกรมร้านหนังสือออนไลน์ขนาดเล็ก (Micro Commerce) ที่พัฒนาขึ้นเป็นมินิโปรเจกต์ในรายวิชา Advance Programming โดยเขียนด้วยภาษา Dart และใช้ Flutter ในการพัฒนาแอปพลิเคชัน

โปรเจกต์นี้ใช้ Cloud Firestore เป็นฐานข้อมูล และใช้ Cloudinary สำหรับจัดเก็บไฟล์และรูปภาพ มีวัตถุประสงค์เพื่อศึกษาและทำความเข้าใจการพัฒนาแอปพลิเคชันด้วย Flutter รวมถึงการเชื่อมต่อและใช้งานบริการจัดเก็บข้อมูลบนคลาวด์

## เครื่องมือและไลบรารีที่ใช้

- **Dart และ Flutter** — ภาษาและเฟรมเวิร์กสำหรับพัฒนาแอปพลิเคชัน
- **Firebase Core** — เชื่อมต่อและเริ่มต้นใช้งาน Firebase
- **Firebase Authentication** — จัดการการยืนยันตัวตนผู้ใช้
- **Cloud Firestore** — จัดเก็บและจัดการข้อมูลของแอปพลิเคชัน
- **Firebase Cloud Messaging** — รองรับการรับการแจ้งเตือน
- **HTTP** — ส่งคำขอไปยังบริการภายนอก เช่น Cloudinary
- **Provider** — จัดการสถานะของแอปพลิเคชัน
- **GoRouter** — จัดการเส้นทางและการนำทางภายในแอปพลิเคชัน
- **Image Picker** — เลือกรูปภาพจากอุปกรณ์
- **Cached Network Image** — โหลดและแสดงรูปภาพจากเครือข่ายพร้อมแคช
- **Intl** — จัดรูปแบบวันที่ ตัวเลข และข้อมูลตามรูปแบบที่กำหนด
- **QR Flutter** — สร้างและแสดง QR Code
- **Cupertino Icons** — ใช้ชุดไอคอนรูปแบบ iOS

สำหรับการทดสอบและตรวจสอบคุณภาพโค้ด ใช้ **Flutter Test** และ **Flutter Lints** ตามลำดับ
